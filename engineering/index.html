🧩 UDT / 程序库 · 多实例 / 软件单元

UDT（PLC 数据类型）把设备属性打包为结构体，配合 FB 多实例、库工程、软件单元（Software Unit）打造项目通用标准块，换项目直接"复制粘贴"。

UDT 示例：电机状态结构

// UDT_Motor（自定义数据类型）
STRUCT
    RunCmd    : Bool;     // 启动命令
    Feedback  : Bool;     // 接触器反馈
    Overload  : Bool;     // 热过载报警
    Current   : Real;     // 运行电流 A
    RunSecs   : DInt;     // 累计运行秒
    LastFault : Word;     // 上次故障码
END_STRUCT;

// DB 中批量定义
"DB_Devices".Conveyor_A : UDT_Motor;
"DB_Devices".Conveyor_B : UDT_Motor;

FB 多实例 & 软件单元

// FB_Motor（一个 FB 管所有电机）
#Status := #Device; // 传接口
IF #Status.Overload THEN
    #Alarm := TRUE; #Status.RunCmd := FALSE;
END_IF;

// OB1 中多实例调用
"FB_Motor_DB1"(Device := "DB_Devices".Conveyor_A);
"FB_Motor_DB2"(Device := "DB_Devices".Conveyor_B);

// 软件单元（TIA V18+）
// → 库文件夹右键 → 创建软件单元
// → 打包 FB + UDT + DB，一键导入新工程

🔀 版本管理 VCI / Git / AI Copilot（TIA V20+）

VCI 导出 Git 流程

1. TIA V20+：项目 → 版本控制 → 导出到 VCS
2. 选导出路径 → 生成文件树（每个 CPU 一个文件夹）
3. 添加 .gitignore（过滤 *.bak、*.log、临时目录）
4. git init / git remote add origin 
5. git add -A → git commit -m "init project v1.0" → git push

日常提交：导出 → git diff 审查 → commit → push
合并冲突：优先用 TIA 导入两端版本再手动解决。

AI Copilot（V20/V21）

TIA 内置 AI Copilot 支持 SCL 代码生成、块注释、解释 LAD 段、调用系统块模板。

  • 新建 SCL 块 → 在 Copilot 栏输入「写一个位置式 PID，含抗积分饱和」
  • 选中现有 LAD → 让 Copilot 翻译成中文解释与 SCL 对照
  • 「生成 UDT 包含一个阀门的 8 个常见字段」
  • 注意：生成代码必须人工逐条审查，禁止直接下载。

🎮 虚拟调试 PLCSIM Advanced + SIMIT + NX MCD

Step 1 · PLCSIM Adv

虚拟 PLC，可仿真 PROFINET 网络、OPC UA、通信伙伴，支持 TIA StartDrive 驱动仿真。下载编译后直接加载。

Step 2 · SIMIT 对象仿真

构建被控对象模型（电机、气缸、阀门、传感器），与 PLCSIM 信号对接，实时模拟物理过程。代替真实设备测试 80% 的控制逻辑。

Step 3 · NX MCD 机电联调

把 NX 3D 机械装配导入 MCD，分配刚体/铰链/运动副，对接 SIMIT 与 PLC，实现机电一体化虚拟调试——现场只装一次。

🔐 安全编程 · Know-How / 访问控制

块级加密 Know-How Protect

右键 FB/FC → 专有技术保护
→ 设置密码（英文数字 8+ 位，务必备份密码表）
→ 下载后 CPU 中代码以乱码显示，只暴露接口
→ 打开需输入密码。支持批量导出带保护的库。

⚠️ 注意：解密需要密码，丢失密码=块不可用。
核心标准库建议加密；客户可修改的参数 DB 不加密。

项目用户管理 + 访问控制

项目树 → 用户管理 → 添加角色
→ Viewer（只读）/ Operator（可操作 HMI）
→ Engineer（可下载/改逻辑）/ Admin（全部权限）
→ 块级权限：部分 FB 仅 Engineer 以上可见

PLC 硬件属性 → 保护
→ 访问级别 1~4：
   1. 无保护
   2. 读/写密码
   3. 下载+在线监控密码
   4. 完全访问 + HMI 读写密码
激活后先测试密码是否正确再投入。
