避坑经验帖

🚫 路径千万不要有中文

TIA Portal V17/V18 对中文路径极其敏感，C:\博途安装\ 会导致编译报 85xx 未知错误。安装路径、项目路径、用户名全用英文。推荐：C:\TIA\Proj\C100 这样。

⚠️ M 区是坏习惯，尽早用 DB 符号

M0.0/MW10/MD20 没有语义、不支持 S7 通信 PUT/GET 优化寻址、导入导出难。全部变量进 DB，用符号寻址 "DB".Tag 带语义。

✓ 优化块访问默认开启

S7-1200/1500 默认优化块访问，不要用绝对地址 %DB1.DBW0。只有跨 CPU S7 PUT/GET 通信、Modbus TCP 寄存器才需要「非优化块访问」——单独建一个 NonOpt DB。

✓ LAD 位逻辑 + SCL 运算混编

纯 SCL 的位逻辑监控非常丑（没有触点流动），纯 LAD 的批量赋值/算法臃肿。混编才是最优解：设备启停、置复位、互锁放 LAD；数学运算、数组、解析放 SCL。

✓ OB35 放 PID、通信、运动

OB1 扫描周期波动（通常 1-10ms），但 PID / 伺服报文 / TRACE 采样需要稳定周期。PID_Compact、工艺对象、循环通信放 OB35（100ms）或 OB32（10ms），Ts 参数匹配。

⚠️ S7-GRAPH 写完必编译两次

GRAPH 第一次编译生成背景逻辑，第二次编译才生成 S7 执行代码。只编一次会出现程序逻辑不更新的灵异现象。
