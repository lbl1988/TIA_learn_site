🔁 PLC 扫描周期原理

PLC 的工作方式是 循环扫描，而非 PC 的中断响应。每个扫描周期分为 4 个阶段：

1初始化
→
2输入采样
读 I 区 → 写入输入映象区
→
3程序执行
CPU 逐条执行 OB/FB/FC
→
4输出刷新
输出映象区 → 写 Q 区
→
↺ 下一周期

关键概念：

  • 扫描时间 (Scan Cycle Time)：S7-1200 通常 1~10ms，S7-1500 约 0.5~3ms。程序越长扫描越慢。
  • 输入映象区：扫描周期开始时锁存 I 端子状态，周期内即使外部信号变化，映象区不变。
  • 输出映象区：程序执行结果暂存于此，周期末尾统一刷新到 Q 端子。
  • 立即刷新 (Immediate I/O)：用 WIW（立即读）/ WOW（立即写）可跳过映象区，适合高速响应。
  • 保持型扫描：S7-1200 默认启用，扫描周期超时自动触发 OB85 诊断。

I 区输入映象区 Input

PLC 扫描周期 开始时将外部输入端子（数字量 DI / 模拟量 AI）状态读入 I 区。程序执行过程中读取的 I 值始终是这个快照，不会随外部变化而变化。

// I 区寻址示例
%I0.0  // 位寻址（第 0 字节第 0 位）
%IW0   // 字寻址（AIW0 模拟量输入值）
%ID0   // 双字寻址（32 位数据）

// 推荐：使用符号寻址
"StartButton"  // 对应 I0.0，可读性好

💡 实际应用：急停按钮接 I0.0，传感器接 I0.1~I0.7，模拟量温度传感器接 AIW256。

Q 区输出映象区 Output

程序执行过程中运算的结果暂存于 Q 区，扫描周期 末尾统一写入输出端子（DO / AQ）。因此同一周期内 Q 区可能被多次赋值，但只有最后一次生效。

// Q 区寻址示例
%Q0.1  // 位寻址（电机启动输出）
%QW2   // 字寻址（AQW2 模拟量输出，如 PID 调节输出）

// 自锁电路：Q0.1 同时作为条件和输出
// 扫描周期内读到的 Q0.1 是上一周期的值

💡 实际应用：电机接触器接 Q0.1，气缸电磁阀接 Q0.2，模拟量 PID 输出接 AQW256。

M 区内部标志区 Merker

M 区是 PLC 的 内部存储区，用于存储中间运算结果、状态标志、计数器/定时器当前值。M 区不直接对应外部端子，仅在 CPU 内部运算时使用。

// M 区典型用途
M0.0  // 中间继电器（启保停逻辑中的自锁触点）
M10.0 // 故障标志（电机过载）
MW20  // 运算中间值（计数累积）
MD30  // 32 位运算结果

// M 区保持型：MB0~MB31 断电保持
// S7-1200 M 区总容量：4096 字节

💡 实际应用：自锁逻辑用 M0.0 替代 Q0.1 避免竞争；故障标志用 M10.0~M10.7 做报警汇总。

DB 区数据块 Data Block

DB 区是 用户可定义的存储区，用于存储大量参数、配方、运行数据。S7-1200/1500 推荐使用 优化块访问（默认开启），通过符号名访问，不再使用绝对地址。

// DB 区访问方式
// 传统绝对寻址（非优化块）
%DB1.DBD0   // 数据块 1 的双字偏移 0

// 推荐符号寻址（优化块）
"MotorDB".CurrentSpeed   // 读电机当前转速
"RecipeDB".Tank1.Volume  // 读配方罐 1 容量

// DB 类型
// ① 实例 DB（背景 DB）：绑定 FB/FC 接口
// ② 全局 DB：通用数据存储
// ③ UDT 类型 DB：用户自定义数据结构

💡 最佳实践：每个设备配一个独立 DB（如 Motor_DB、Conveyor_DB），用 UDT 定义结构，多实例 FB 共享。

🔘 触点与线圈：LAD 基本元素

LAD（梯形图）用 继电器图形符号 表达逻辑，最基本的两个元素是 触点 和 线圈：

元素符号说明对应指令
常开触点─┤ ├─条件为 ON 时导通|--|
常闭触点─┤/├─条件为 OFF 时导通|--|/|
上升沿触点─┤↑├─信号 0→1 跳变时导通 1 周期|--P|
下降沿触点─┤↓├─信号 1→0 跳变时导通 1 周期|--N|
输出线圈─( )─条件满足时输出 ON-( )
反向线圈─(/)─条件满足时输出 OFF-(/)
立即线圈─(I)─立即刷新输出（跳过映象区）-(I)
常开 vs 常闭触点

常开触点（NO）：对应继电器逻辑中的"断开"状态。当 I0.0 = 1（按钮按下）时，触点闭合导通；I0.0 = 0（按钮松开）时，触点断开。

// 常开触点示例
// I0.0 是启动按钮（常开）
// 按钮松开 → I0.0 = 0 → 触点断开 → Q0.1 无输出
// 按钮按下 → I0.0 = 1 → 触点闭合 → Q0.1 有输出

|-- I0.0 --|-- Q0.1 (电机) --|
  常开触点     输出线圈

常闭触点（NC）：对应继电器逻辑中的"闭合"状态。当 I0.0 = 1（按钮按下）时，触点断开；I0.0 = 0（按钮松开）时，触点闭合导通。

// 常闭触点示例（急停按钮）
// I0.1 是急停按钮（常闭接入）
// 正常 → I0.1 = 1 → 常闭触点断开？不！
// 急停未按下：I0.1 = 1 → 常闭触点 ┤/├ 导通
// 急停按下：I0.1 = 0 → 常闭触点 ┤/├ 断开

|-- I0.0 --┤/├── Q0.1 (电机) --|
  启动    急停(常闭)  输出

💡 硬件配线：急停按钮应接 常闭触点 到 PLC 输入端。正常状态 I 为 1（ON），急停按下时 I 变为 0（OFF）。这样即使线缆断裂也会触发停机，安全回路设计原则。

启保停（自锁）电路

这是 LAD 中最经典的电路，用 自身触点锁定输出，实现"启动后持续运行，直到停止"：

// 启保停（自锁）完整电路
// 输入：I0.0 启动按钮（常开）
//       I0.1 停止按钮（常开）
// 输出：Q0.1 电机运行

|-- I0.0 --┬─┤/├──( Q0.1 )--|
  启动     │  I0.1 停止   输出
           │  (常闭)
           └─ Q0.1
              自锁触点(常开)

工作原理：

  1. 按下 I0.0 → 导通 → Q0.1 得电输出
  2. Q0.1 常开触点闭合 → 替代 I0.0 持续导通（自锁）
  3. 松开 I0.0 → 不影响，自锁维持
  4. 按下 I0.1（停止）→ 常闭触点断开 → Q0.1 失电
  5. 松开 I0.1 → 回路重新就绪，等待下次启动

💡 实际项目中建议用 M 区中间变量 做自锁，避免 Q 区竞争问题：Motor_StartReq（M0.0）作为自锁标志，最后驱动 Q0.1。

🔄 S/R 置位与复位指令

S（Set 置位） 把目标地址设为 1 并保持，R（Reset 复位） 把目标地址设为 0 并保持。与线圈的区别是：触发一次即可永久改变状态，无论条件是否持续。

指令符号功能触发方式
S─( S )─置位为 1 并保持条件导通时
R─( R )─复位为 0 并保持条件导通时
RSRS 触发器优先复位的双稳态S/R 同时有效时 R 优先
SRSR 触发器优先置位的双稳态S/R 同时有效时 S 优先
S/R 与线圈的区别
// 普通线圈：条件断开 → 输出立即断开
|-- I0.0 ----( Q0.1 )--|   // I0.0=1 时 Q0.1=1
                            // I0.0=0 时 Q0.1=0

// S 置位线圈：条件断开 → 输出保持为 1
|-- I0.0 ----( S Q0.1 )--|  // I0.0=1 时 Q0.1 置 1
                             // I0.0=0 时 Q0.1 仍为 1

|-- I0.1 ----( R Q0.1 )--|  // I0.1=1 时 Q0.1 复位为 0

S/R 规则：

  • 同一地址的 S 和 R 可以写在不同网络（Network），不必紧挨着。
  • 扫描周期内，最后执行的那条有效（S 和 R 同时导通时取决于程序位置）。
  • S/R 触发器块（RS/SR）可在同一位置处理 S 和 R，带优先级。
应用场景：故障锁存

当故障是 脉冲型（如传感器瞬时触发），需要用 S/R 锁存，直到人工复位：

// 故障锁存电路
// I0.2 过载传感器（脉冲型，可能瞬时触发）
// I0.3 故障复位按钮
// M10.0 故障标志（锁存）

|-- I0.2 ----( S M10.0 )--|   // 过载触发 → 置位故障
|-- I0.3 ----( R M10.0 )--|   // 人工复位 → 清除故障

// 用 M10.0 控制报警灯和停机
|-- M10.0 --┤/├──( Q0.1 电机 )--|  // 故障时停机
|-- M10.0 ----( Q0.5 报警灯 )--|   // 故障时亮灯

💡 这是工业项目中最常用的锁存方式，所有故障报警都应使用 S/R 锁存，确保瞬时故障不遗漏。

⏱ 定时器指令详解（TON / TOF / TP / TONR）

定时器是 PLC 中最常用的指令之一，S7-1200 推荐使用 IEC 定时器（TON/TOF/TP/TONR），比传统 S5 定时器更灵活、精度更高。

|-- I0.0 ----[ TON T1, T#5S ]----|
  触发输入        ↑       ↑
              定时器   预设时间
  
// 时序图
// IN:  ┌───┐              ┌───
//      │   │              │
//      ┘   └──────────────┘

// 时序图

🔢 计数器指令详解（CTU / CTD / CTUD）

计数器用于 事件计数，S7-1200 使用 IEC 计数器，支持加计数、减计数和双向计数。

类型功能计数输入复位输出
CTU加计数CU 上升沿 +1R 复位为 0CV ≥ PV 时 Q=1
CTD减计数CD 上升沿 -1R 复位为 PVCV ≤ 0 时 Q=1
CTUD双向计数CU/CD 均可R 复位同 CTU/CTD
CTU 加计数器详解
// CTU 加计数器梯形图
|-- I0.0(传感器) --[ CTU C1, PV=100 ]----|
  计数脉冲    ↑         ↑
              计数器    预设值(100)

// 参数说明
// CU：计数脉冲输入（上升沿 +1）
// R：复位输入（高电平复位为 0）
// PV：预设值（INT 类型，最大 32767）
// CV：当前计数值（实时更新）
// Q：输出（CV ≥ PV 时置 1）

// 应用：产品计数 + 满箱报警
|-- I0.0(光电传感器) --[ CTU C1, PV=50 ]----|  // 每 50 个一箱
|-- C1.Q ----( Q0.3(满箱报警) )--|             // 满箱时亮灯
|-- C1.Q ----( S Q0.4(推包气缸) )--|           // 触发推包
|-- I0.1(推包完成) --( R C1 )--|               // 推完复位计数
CTD 减计数器 + CTUD 双向
// CTD 减计数器：从预设值递减到 0
|-- I0.0(出库信号) --[ CTD C2, PV=10 ]----|
|-- C2.Q ----( M20.1(缺货报警) )--|  // 减到 0 时报警

// CTUD 双向计数器：可加可减
|-- I0.0(进库) --┬─[ CTUD C3, PV=100 ]----|
|-- I0.1(出库) --┘
|-- C3.CV 实时库存值
|-- C3.Q ----( Q0.5(库存满) )--|

// 计数器扩展
// S7-1200 单个计数器计数上限：32767（INT）
// 大范围计数可用 DINT 计数器（TIA V17+）
// 或用 M 区/DB 区自行累加：
|-- I0.0(脉冲) --[ ADD MW10, 1, MW10 ]--|  // MW10 = MW10 + 1
|-- MW10 >= 1000 --( Q0.1 )--|              // 达 1000 时输出

🔍 比较运算指令（CMP）

比较指令用于 比较两个数值，输出 BOOL 结果（TRUE/FALSE），在 LAD 中以 功能框（FBD 风格）形式出现，驱动后续触点/线圈。

指令符号功能适用类型
CMP ====等于INT / DINT / REAL / STRING
CMP !=!=不等于INT / DINT / REAL / STRING
CMP >>大于INT / DINT / REAL
CMP >=>=大于等于INT / DINT / REAL
CMP <<小于INT / DINT / REAL
CMP <=<=小于等于INT / DINT / REAL
LAD 中使用比较框

在 LAD 中，比较框的 EN 端（使能）必须有逻辑流入，OUT 端输出 BOOL 结果，可直接驱动触点：

// 比较框梯形图
|-- I0.0(启动) --[ CMP >= ]----( Q0.1(加热) )--|
                      ↑    ↑
                   MW10  500
                  (温度) (设定值)

// 含义：当温度 MW10 >= 500 且启动信号 I0.0=1 时，Q0.1 输出
// 注意：比较框 EN 端需要前置条件，OUT 端结果作为导通条件

// 复杂比较：多条件组合
|-- I0.0 --┬─[ CMP >= ]──┬─[ CMP <= ]──( Q0.1 )--|
           │   MW10 >= 500  │   MW10 <= 800
           │                │
           └────────────────┘
              (AND 串联)
数据类型与注意事项
// INT vs DINT vs REAL 选择
// INT：整数（-32768 ~ 32767）→ 适合计数、简单比较
// DINT：双整数（-2³¹ ~ 2³¹-1）→ 大范围数值
// REAL：浮点（±3.4×10³⁸）→ 高精度温度/压力/流量

// REAL 比较注意事项
// ❌ 避免直接用 == 比较两个浮点数
CMP == REAL1, REAL2  // 浮点精度问题，可能永远不相等

// ✅ 用误差范围比较
|--[ CMP >= ]--┬--[ CMP <= ]--( M0.0(相等) )--|
     REAL1 - 0.01  │    REAL1 + 0.01
     REAL2         │    REAL2

// 或用 ABS 差值判断
|--[ ABS ]--[ CMP <= ]--( M0.0 )--|
   REAL1 - REAL2   0.01

💡 REAL 比较时建议用 误差范围法，因为浮点数存在精度误差（如 0.1 + 0.2 ≠ 0.3）。推荐误差范围 0.001~0.01。

⚡ 逻辑运算指令（AND / OR / XOR / NOT）

逻辑运算对 BOOL / WORD / DWORD 类型数据进行逐位布尔运算：

指令功能规则典型用途
AND按位与全 1 出 1提取特定位（屏蔽）
OR按位或有 1 出 1设置特定位
XOR按位异或不同出 1位翻转、奇偶校验
NOT按位取反1 变 0，0 变 1状态反转
NAND按位与非全 1 出 0复合逻辑
NOR按位或非有 1 出 0复合逻辑
LAD 中的逻辑运算
// 1. 触点串联 = AND 逻辑
|-- I0.0 -- I0.1 --( Q0.1 )--|   // I0.0 AND I0.1

// 2. 触点并联 = OR 逻辑
|-- I0.0 --┬──( Q0.1 )--|          // I0.0 OR I0.1
|-- I0.1 --┘

// 3. 显式 AND/OR 功能框（处理 WORD/DWORD）
|-- I0.0 --[ AND_W ]----( Q0.1 )--|
              ↑   ↑
           MW10 MW12
// AND_W：字与运算 MW10 AND MW12 → 结果存 MW14

// 4. NOT 取反
|-- I0.0 --[ NOT ]----( Q0.1 )--|
// NOT：I0.0=1 → 输出 0；I0.0=0 → 输出 1

// 5. XOR 异或（用于状态差异检测）
|--[ XOR_W ]--[ CMP != ]--( M0.0(变化标志) )--|
   MB10  MB11
位操作应用：状态字解析

逻辑运算最常见的用途是 解析状态字（WORD/DWORD），提取或设置特定标志位：

// 假设 MW10 是电机状态字，各位定义：
// Bit0: 运行   Bit1: 停止   Bit2: 过载
// Bit3: 欠压   Bit4: 通信故障  Bit5: 就绪

// 提取 Bit0（运行标志）
|--[ AND_W ]--[ CMP != ]--( Q0.1(运行指示灯) )--|
   MW10   16#0001    0
// MW10 AND 0x0001 ≠ 0 → Bit0=1 → 电机运行

// 提取 Bit2（过载标志）
|--[ AND_W ]--[ CMP != ]--( Q0.5(过载灯) )--|
   MW10   16#0004    0
// MW10 AND 0x0004 ≠ 0 → Bit2=1 → 过载

// 清除 Bit2（复位过载）
|-- I0.1(复位) --[ AND_W ]--( MW10 )--|
                   MW10    16#FFFB
// MW10 AND 0xFFFB：将 Bit2 置 0，其余位不变

💡 位掩码速查：Bit N 的掩码值 = 2^N。Bit0 = 0x0001，Bit3 = 0x0008，Bit7 = 0x0080。清除 Bit N 用 全1 XOR (2^N)。

➡ 移位与循环移位指令

移位指令将 WORD / DWORD 的各位左移或右移 N 位，空出的位补 0 或符号位。循环移位则将移出的位补到空位：

指令功能空位填充典型用途
SHL逻辑左移低位补 0乘法（×2^n）
SHR逻辑右移高位补 0除法（÷2^n）
SHL_DI / SHR_DI双整数移位同上32 位移位
ROL循环左移移出位补到空位位旋转、流水灯
ROR循环右移移出位补到空位位旋转
移位原理与应用
// SHL 左移：各位左移，低位补 0
// MW10 = 0000 0001 0100 0000 = 0x0140
SHL MW10, 2  // 左移 2 位
// 结果: 0000 0101 0000 0000 = 0x0500
// 相当于 MW10 × 4（2²）

// SHR 右移：各位右移，高位补 0
SHR MW10, 3  // 右移 3 位
// 结果: 0000 0000 0010 0010 = 0x0022
// 相当于 MW10 ÷ 8（2³）

// 用移位做快速乘除（ powers of 2 ）
SHL MW10, 1  // MW10 × 2
SHL MW10, 4  // MW10 × 16
SHR MW10, 2  // MW10 ÷ 4
流水灯实现（ROL 循环移位）

循环移位最经典的应用是 流水灯效果，8 路 LED 依次点亮：

// 流水灯：8 路 LED 循环点亮
// 初始化：MW20 = 0x0001（只有 Bit0 亮）
|-- SM0.1 --[ MOVE ]--( MW20 )--|
               16#0001

// 用 TON 定时器每 500ms 触发一次
|-- I0.0(运行) --[ TON T1, T#500MS ]--|
|-- T1.Q --[ ROL ]--( MW20 )--|
            MW20   1
// 效果：0x0001 → 0x0002 → 0x0004 → ... → 0x8000 → 0x0001 → ...

// 反向流水灯用 ROR
|-- T1.Q --[ ROR ]--( MW20 )--|

// 输出到 8 个 LED
|-- MW20 --( QW0 )--|  // Q0.0~Q0.7 对应 8 路 LED

💡 扩展到 16 路流水灯用 MW（字 = 16 位），32 路用 MD（双字 = 32 位）。循环移位的关键是 初始化一个单 1 位，每次移动 1 位即可。
