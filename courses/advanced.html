TRACE 轨迹与数据采集

TIA Portal 内置 TRACE 功能：变量触发采样 + 逻辑分析器，S7-1200 2 条 TRACE 配置/ 16 信号、S7-1500 更多；三种触发模式（立即记录 / 变量触发 / 无触发器监视）；采样周期与 OB 同步；记录保存到存储卡、导入离线对比。故障"黑匣子"必备技能。
// TRACE 配置步骤摘要
1. 项目树 → CPU → 轨迹 → 添加新 Trace
2. 信号 // 最多 16 个：位/整数/实数/时间
3. 采样 OB：OB1 循环 或 OB35 中断；采样频率 N
4. 触发：立即 / 变量触发 (Err = 1) / 无触发器监视
5. 下载 → 激活 → 触发后上传 → 保存记录
6. 组合测量：不同记录信号叠加对比分析
逻辑分析器触发采样存储卡组合测量故障黑匣子

综合毕业项目

项目 A · 产线控制

S7-1500 + 2 台 V90 伺服 + ET 200SP 远程 IO + TP1200 HMI：上料→搬运→定位→检测→出料。集成 ISA-88 状态机 + TRACE 追踪 + OPC UA 上传 MES。

项目 B · 冗余系统

S7-1515R 软冗余（MRP 环网）+ SCALANCE X 交换机 + S2 冗余 IO。模拟单链路/单 CPU 故障，验证 300ms 切换不中断运行。

项目 C · SCADA + 安全

F-CPU 急停/安全门程序 + WinCC SCADA 变量记录/报警/报表 + 用户审计追溯。符合 SIL3 安全验证记录。
