ISA-88 程序架构 / 状态机 ●配套

ISA-88 批次标准：物理模型（Area→Unit→EquipMod→CtrlMod）+ 程序模型（Procedure→Operation→Phase），SCL CASE OF 驱动 Phase 6 状态机（Idle/Running/Paused/Held/Complete/Aborted），Running 内含加料/升温/保温/出料 4 工艺子步。
// FB_BatchPhase.scl · CASE 状态机片段
CASE #State OF
    0:  // Idle
        IF #CmdStart THEN #NextState := 10; END_IF;
    10: // Running（工艺子步 CASE 嵌套）
        IF #CmdAbort THEN #NextState := 99;
        ELSIF #CmdPause THEN #NextState := 20;
        ELSE
            CASE #SubStep OF
                10: #FeedValve := TRUE;
                    IF #LevelHi THEN #SubStep := 20; END_IF;
                20: #Heater := #PIDOutput;
                    IF #ActualTemp >= #SetTemp THEN #SubStep := 30; END_IF;
                30: // 保温 + IEC 计时; ...;
                40: #DrainValve := TRUE;
                    IF #DrainDone THEN #NextState := 90; END_IF;
            END_CASE;
        END_IF;
    99: // Aborted 异常处理;
END_CASE;

关键原则 & 避坑

  • 按任务选语言：位逻辑类继续用 LAD（可读性+监控方便）；批量运算/PID/解析用 SCL；顺序工艺用 S7-GRAPH。不要混用。
  • SCL 定时器避坑：IEC 定时器必须放在主路径（IF 外部），条件不满足时无法复位会乱跳。
  • 优化块访问默认开启：绝对寻址%DB1.DBW0 已过时，符号寻址 `"DB".Tag` 更安全。
  • ISA-88 状态机命令优先级：Abort（最高）> Pause/Hold > 工艺子步。CASE 里先判断命令。
  • PROFINET 设备名唯一：拓扑视图里分配设备名和 IP，下载前用"分配设备名称"扫。
